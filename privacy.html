SpoilWipe Privacy Policy

Effective Date: July 27, 2025

Information We Collect

SpoilWipe does not collect, track, or store any personally identifiable information (PII). We do not transmit any user data to external servers.

Data Stored Locally

SpoilWipe uses chrome.storage.sync to save:

  • Blocked spoiler keywords entered by the user
  • Smart keyword history (optional)
  • Extension settings (e.g. blur toggle, overlay preferences)

All data is stored locally in your browser, and only synced across your Chrome profile if sync is enabled.

External APIs

SpoilWipe connects to the TMDB API to fetch movie metadata (e.g. character names, cast, keywords). This data is:

  • Publicly available
  • Used only for spoiler detection
  • Never linked to any personal user info

We do not share any data with TMDB.

Third-Party Services

SpoilWipe does not use:

  • Analytics or tracking tools
  • Advertising networks
  • External scripts or trackers

Your Control

You can:

  • View or delete your saved keywords at any time
  • Clear extension data via Chrome’s extension settings
  • Uninstall the extension to remove all associated data

Summary

SpoilWipe is designed with user privacy in mind. We don’t collect personal data or share anything with third parties. All spoiler filtering is performed locally in your browser.
